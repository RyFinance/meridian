# Beyond-menu wave 2 — data unlock and development results

**POSITIVE: none.** Wave 2 ran **two** frozen, preregistered, development-only candidates; both FAIL the fixed joint rule. Their 2016–2025 holdouts remain locked. This is research-only evidence, with no direct ETF implementation or owner/forward registration.

## 0. Proposed A4 event-effective-N patch and FOMC re-report

[The proposed A4 patch](../../research/A4_PATCH_EVENT_EFFECTIVE_N.md) caps a sparse event design's effective N at `min(calendar-time N_eff, event count, event count / event-dependence D)`, where event dependence uses event-order HAC, preregistered cluster sums and payoff overlap. It is a power/reporting guard, **not an uncalibrated change to A4's p-value**. Three unit tests pass. In a 40,000-path zero-mean synthetic experiment with 19 clusters of eight events and within-cluster correlation 0.35, the false-pass rate of a *misused event-mean t* is 42.01% with the daily N treated as event N, 18.99% when capped only by event count, and 5.63% with the estimated event/cluster cap (5.11% with the true design effect). These are not size claims for the actual A4 p algorithm, which does not use effective N. The [simulation record](event_n_simulation.json) preserves the design and counts.

The [FOMC re-report](fomc_event_n_rereport.json) uses only saved wave-1 development outputs: 153 scheduled events, 19 year clusters, event `D=1.1935`, and **event-effective N=128.2**, replacing the misleading daily-series effective N of 2,964.9. The A4 calibrated **p remains 0.0625**, because its algorithm never consumed the old effective-N figure. This is a **re-analysis, not a new trial**; the fixed wave-1 `p < 0.0125` gate still fails. The old result files, strategy and holdout were untouched.

## 4. Project-wide count and methodological limits

[PROJECT_TRIAL_TALLY.md](PROJECT_TRIAL_TALLY.md) gives a **single documented tally of 298 candidate entries** across the historical 269-row trial inventory, 23 completed cycle-6 log IDs, four wave-1 trials and two wave-2 trials. It cannot honestly be called the exact number of independent return-bearing tests: the historical inventory includes non-trials and estimates of unlogged search, while another model's work can continue. Project-wide significance is therefore **not certifiable from this denominator**. The fixed wave-2 rule correctly uses its two actual runs; both fail even without a project correction.

The central data limitation is that JKP supplies public, author-calculated factor returns, not the paid constituent-level PIT CRSP/Compustat panel, order fills, stock borrow or fully reconstructible delisting cashflows. The 40/100 bp monthly drags are declared research proxies rather than executable global-short costs. The source's 2026 refresh can revise earlier return rows; the content-addressed snapshot preserves exactly the version used here. No strategy was retuned, no null was given a rescue narrative, and no crypto, validation-period return, broker, registry, order, commit or push was involved.
